# SmartStudy AI

SmartStudy AI is a personal AI-powered study assistant designed to help students manage their study time effectively. This application allows users to input their name, daily study hours, and subjects they wish to study, providing a personalized learning experience.

## Features

- User-friendly interface for entering study details.
- Tracks daily study hours and subjects.
- Redirects to a dashboard for monitoring study progress.

## Files Overview

- **student.html**: Contains the HTML structure for the application, including input fields for student information and a button to start learning.
- **dashboard.html**: Serves as the dashboard for users to view their study progress and other relevant information.
- **style.css**: Contains the CSS styles that define the visual appearance of the application.
- **vercel.json**: Configuration file for deploying the application on Vercel, including routing and build settings.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the project in your preferred code editor.
3. Open `student.html` in a web browser to start using the application.
4. Customize the `style.css` file to change the visual appearance as desired.

## Deployment

To deploy the application on Vercel:

1. Ensure you have a Vercel account.
2. Install the Vercel CLI if you haven't already.
3. Run `vercel` in the project directory and follow the prompts to deploy.
